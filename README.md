# Personal Expense Tracker

## Introduction

Personal Expense Tracker is a simple Python project that helps users record their daily expenses and calculate the total amount spent by them.

## Features

* Add a new expense
* View all expenses
* Calculate total expenses
* Exit the program

## Technologies Used

* Python
* Lists
* Variables
* If-else statements
* While loop
* For loop
* User input and output



```bash
python main.py
```

## How to Use

When the program starts, it shows a menu of options such as:

1. Adding Expense
2. Viewing Expenses
3. Totalling Expense
4. Exit

Enter the number of your choice and follow the instructions shown on the screen.

## For Example

```text
--- Personal Expense Tracker ---
1. Add Expense
2. View Expenses
3. Total Expense
4. Exit

Enter your choice: 1
Enter expense name: Food
Enter amount: 100
Expense added successfully!
```

## Project Scope

This project is designed for students and beginners who want to keep track of simple daily expenses and avoid excessive spending. It demonstrates basic Python programming concepts such as lists, loops, conditions, input, output, and arithmetic operations.

## Limitations

* Expenses are stored only while the program is running.
* Data is not permanently saved.
* The project does not use a database.
* The project does not have a graphical user interface.
